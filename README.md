# Frais Proxi

Première version gratuite d'une application de gestion des DLC.

## Mise en ligne avec GitHub Pages

1. Créer un dépôt GitHub nommé `frais-proxi`.
2. Envoyer tous les fichiers de ce dossier à la racine du dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Choisir la branche `main` et le dossier `/ (root)`.
6. Enregistrer.
7. GitHub donnera une adresse `https://TON-PSEUDO.github.io/frais-proxi/`.

## Important
Cette version sauvegarde les données dans le navigateur de chaque téléphone. Elle ne synchronise donc pas encore les données entre employés/téléphones.

La prochaine étape pourra être d'ajouter une base de données en ligne, les comptes employés et le scan code-barres.
